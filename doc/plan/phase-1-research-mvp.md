# Phase 1 - 真实 Research MVP

## 目标

用真实 A 股日线数据跑通一个策略回测，并让后端 API 返回真实结果，而不是静态样例或随机指标。

## 范围

- 数据层：真实日线行情导入、清洗和落库。
- 策略层：最小策略接口和一个可运行示例策略。
- 回测层：日频回测核心循环、交易成本、基础 A 股规则。
- API 层：创建回测任务、查询回测结果、返回权益曲线和指标。

## 任务清单

- [x] 设计真实行情数据导入路径，优先支持 AKShare 或本地 CSV。
- [x] 实现 `MarketBarDaily` 的导入服务，支持 symbol、trade_date、OHLCV、amount、adjusted_close。
- [x] 增加最小数据清洗：去重、日期排序、缺失字段检查、异常价格检查。
- [x] 实现基础 A 股交易规则标记：停牌、涨跌停、T+1 所需字段预留。
- [x] 定义最小策略运行接口：初始化、生成信号、调仓。
- [x] 增加一个内置示例策略：双均线或 ROE/PE 选股。
- [x] 实现日频回测循环：读取行情、生成目标权重、撮合成交、更新现金和持仓。
- [x] 实现交易成本：佣金、最低佣金、印花税、滑点。
- [x] 计算核心指标：累计收益、年化收益、最大回撤、Sharpe、胜率、换手。
- [x] 将 `BacktestTask`、`BacktestRun`、`BacktestMetric`、`EquityPoint` 接入真实落库流程。
- [x] 将 `/api/v1/backtests` 从静态样例改为读取真实任务和结果。
- [x] 增加后端测试，覆盖数据导入、示例策略回测、指标计算。

## 验收标准

- [x] 本地可以导入至少 2 只 A 股或示例 CSV 日线数据。
- [x] 示例策略能完成一次真实日频回测。
- [x] 回测结果包含真实权益曲线、回撤曲线和核心指标。
- [x] `/api/v1/backtests/{task_id}` 能查询真实任务状态和结果。
- [x] 测试覆盖核心计算路径。

## 风险

- AKShare 依赖网络和接口稳定性，本地 CSV 需要作为离线兜底。
- A 股复权、停牌、涨跌停规则不能一次做满，Phase 1 只做最小可运行版本。
- 不应直接执行任意 LLM 生成代码，策略运行时先使用受控内置策略。
