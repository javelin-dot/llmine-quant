# Phase 3 - 可靠性与可解释性

## 目标

避免策略只在样本内好看，建立过拟合检测、样本外验证、数据血缘和信号解释能力。

## 任务清单

- [ ] 增加样本内和样本外切分配置。
- [ ] 实现 Walk-forward 回测流程。
- [ ] 实现参数扰动分析。
- [ ] 实现滑点敏感性分析。
- [ ] 实现过拟合评分：IS/OOS 收益比、Sharpe 衰减、回撤一致性、参数稳定性。
- [ ] 建立最小 Feature Store：特征名、版本、依赖、计算时间点、是否验证。
- [ ] 建立数据血缘记录：Raw -> Cleaned -> Feature -> Strategy -> Signal -> BacktestRun。
- [ ] 增加规则策略解释：命中条件、排序贡献、过滤原因。
- [ ] 增加报告 API，输出回测摘要、风险摘要、解释摘要。
- [ ] 增加测试，覆盖 Walk-forward、过拟合评分和血缘记录。

## 验收标准

- [ ] 每个策略回测都能标记低/中/高过拟合风险。
- [ ] 每个回测结果能追踪到使用的数据和特征版本。
- [ ] 策略报告能说明收益来源和主要风险来源。
