# Phase 4 - 模拟盘闭环

## 目标

把通过验证的策略接入模拟盘，让信号、订单、持仓、净值和风控形成可持续运行的闭环。

## 任务清单

- [ ] 设计模拟账户、持仓、订单、成交、日度净值模型。
- [ ] 实现策略日终信号生成任务。
- [ ] 实现模拟订单生成和撮合。
- [ ] 实现预交易检查：单票上限、行业上限、现金比例、最大回撤、日亏损。
- [ ] 实现模拟盘 NAV 更新。
- [ ] 将 Portfolio API 改为读取真实持仓、净值和风险预算。
- [ ] 将 Execution API 改为读取真实模拟订单和审批状态。
- [ ] 将 Risk API 改为读取真实风险检查和违规记录。
- [ ] 增加定时任务入口，支持日终批处理。
- [ ] 增加测试，覆盖订单生成、成交、持仓更新和风险拦截。

## 验收标准

- [ ] 一个策略可以进入 paper 状态并生成模拟订单。
- [ ] 模拟盘可以连续运行多个交易日。
- [ ] 前端组合、执行、风控页面展示真实模拟盘数据。
- [ ] 风控违规订单会被拦截并留下审计记录。
