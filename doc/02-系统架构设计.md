## 2. 技术栈选型

### 2.1 后端

| 组件 | 选型 | 理由 |
|------|------|------|
| 语言 | Python 3.11+ | 量化生态最丰富（pandas, numpy, scipy, statsmodels） |
| Web 框架 | FastAPI | 高性能、异步原生、自动生成 OpenAPI 文档 |
| Agent 框架 | LangChain / AutoGen | 快速构建多 Agent 协作工作流 |
| LLM | Claude / GPT-4 / 国产大模型 | 策略生成、代码生成、报告撰写 |
| 时序数据库 | InfluxDB / TimescaleDB | 行情数据高性能读写 |
| 关系数据库 | PostgreSQL | 元数据、账户、策略配置 |
| 缓存 | Redis | 行情缓存、会话、限流 |
| 消息队列 | Redis Stream / RabbitMQ | Agent 间异步通信 |
| 对象存储 | MinIO / AWS S3 | 回测报告、日志、模型文件 |
| 任务调度 | Celery + Redis | 定时任务、回测队列、数据更新 |

### 2.2 前端

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | React 18 + TypeScript | 类型安全、组件化 |
| UI 库 | Ant Design / Shadcn UI | 企业级组件 |
| 图表 | ECharts / TradingView Charting Library | K 线、回测曲线、风险指标 |
| 状态管理 | Zustand | 轻量、TypeScript 友好 |
| 构建 | Vite | 快速 HMR |

### 2.3 基础设施

| 组件 | 选型 | 理由 |
|------|------|------|
| 容器化 | Docker + Docker Compose | 开发/测试环境一致性 |
| 编排 | Kubernetes (二期) | 生产级扩缩容 |
| 监控 | Prometheus + Grafana | 指标采集与可视化 |
| 日志 | ELK Stack / Loki | 集中式日志管理 |
| CI/CD | GitHub Actions | 自动化测试与部署 |

## 3. Agent 架构详解

### 3.1 Agent 通信协议

```python
class AgentMessage(BaseModel):
    msg_id: str           # UUID
    from_agent: str       # 发送方 Agent ID
    to_agent: str         # 接收方 Agent ID（或 broadcast）
    msg_type: str         # 消息类型：task / result / alert / approval_request
    task_id: str          # 关联的任务 ID
    payload: dict         # 业务数据
    timestamp: datetime   # 发送时间
    priority: int         # 优先级：1-5
```

### 3.2 各 Agent 职责

#### Research Agent（研究 Agent）

```
输入：自然语言描述 / 研究主题 / 市场观察
输出：研究报告 + 候选因子/信号 + 数据需求清单

能力：
- 解析用户自然语言，转化为量化研究任务
- 扫描市场结构、板块轮动、风格切换
- 生成候选因子并评估其经济学直觉
- 调用 Data Agent 获取数据验证假设
```

#### Strategy Agent（策略 Agent）

```
输入：研究结论 / 策略模板 / 用户草稿
输出：可执行策略代码 + 参数空间 + 风控规则

能力：
- 基于模板或自然语言生成策略代码
- 自动设计参数空间与优化目标
- 生成策略文档（逻辑说明、假设、风险点）
- 提交 Backtest Agent 进行验证
```

#### Backtest Agent（回测 Agent）

```
输入：策略代码 + 参数 + 数据范围 + 约束条件
输出：回测报告 + 绩效指标 + 过拟合评估

能力：
- 执行多组参数回测
- Walk-forward 交叉验证
- 滑点敏感性分析
- 未来函数/幸存者偏差检测
- 样本内/样本外一致性评估
- 生成可视化报告
```

#### Risk Agent（风控 Agent）

```
输入：策略回测结果 / 组合持仓 / 市场环境
输出：风险评估报告 + 建议动作 + 熔断信号

能力：
- 三层风控检查（账户/组合/策略）
- 最大回撤、VaR、CVaR 计算
- 压力测试与情景分析
- 自动拦截违规提案
- 熔断规则执行
```

#### Execution Agent（执行 Agent）

```
输入：已审批的订单草案
输出：订单执行状态 + 成交回报 + 异常报告

能力：
- 生成订单草案（价格、数量、拆单策略）
- 对接 QMT/PTrade 下单（二期）
- 监控成交、部分成交、撤单
- 异常处理与重试
```

#### Data Agent（数据 Agent）

```
输入：数据请求（标的/字段/频率/范围）
输出：清洗后的数据集 + 数据质量报告

能力：
- 多源数据采集（AKShare/Tushare/Baostock）
- A 股特有清洗（复权、停牌、ST、退市）
- 数据质量检测（缺失率、异常值、延迟）
- 主备源自动切换
- 数据血缘记录
```

#### Explainability Agent（可解释 Agent）

```
输入：交易信号 / 策略决策 / 模型预测
输出：归因报告 + 置信度分析 + 可视化

能力：
- 因子贡献分解（正负贡献）
- SHAP / Feature Importance（ML 策略）
- 信号触发链路追溯
- 历史相似场景匹配
- 生成自然语言解释
```

#### Portfolio Agent（组合 Agent）

```
输入：候选策略 + 资金约束 + 风险偏好
输出：最优配置方案 + 风险预算分配

能力：
- 均值方差优化
- 风险平价配置
- Black-Litterman 模型
- 相关性分析与分散度评估
- 再平衡信号生成
```

## 4. 数据流设计

### 4.1 策略研发数据流

```
[用户] --自然语言--> [Research Agent] --研究假设--> [Data Agent]
                                                           │
                                                           ▼
[用户] <--报告-- [Explainability Agent] <--归因-- [Backtest Agent]
     ▲                                            ▲
     │                                            │
[Strategy Agent] --策略代码--> [Policy Engine] --审批--> [Risk Agent]
```

### 4.2 交易执行数据流

```
[Strategy Signal] --> [Risk Agent] --检查通过--> [Human Approval] --确认--> [Execution Agent]
       │                  │拒绝                              │拒绝
       ▼                  ▼                                  ▼
  [日志记录]         [拒绝理由]                          [拒绝记录]
```

## 5. 核心领域模型

```python
# 策略 (Strategy)
class Strategy(BaseModel):
    id: str
    name: str
    description: str
    type: StrategyType  # RULE_BASED / ML / PORTFOLIO
    code: str           # Python 代码
    parameters: dict    # 参数字典
    universe: List[str] # 股票池
    frequency: str      # 1d / 1h / 15m
    author: str
    version: str
    status: Status      # DRAFT / BACKTESTING / PAPER / LIVE / PAUSED / ARCHIVED
    risk_rules: List[RiskRule]
    created_at: datetime
    updated_at: datetime

# 回测任务 (BacktestTask)
class BacktestTask(BaseModel):
    id: str
    strategy_id: str
    params_grid: dict           # 参数搜索空间
    start_date: date
    end_date: date
    initial_cash: float
    benchmark: str              # 如 "000300.SH"
    status: TaskStatus
    results: Optional[BacktestResult]
    bias_check: BiasCheckReport
    created_at: datetime

# 回测结果 (BacktestResult)
class BacktestResult(BaseModel):
    task_id: str
    annual_return: float
    max_drawdown: float
    sharpe_ratio: float
    sortino_ratio: float
    calmar_ratio: float
    win_rate: float
    profit_loss_ratio: float
    turnover: float
    trades: List[Trade]
    equity_curve: List[EquityPoint]
    oos_ratio: float            # 样本外/样本内收益比
    overfit_score: str          # LOW / MEDIUM / HIGH
    scenario_results: List[ScenarioResult]

# 风控规则 (RiskRule)
class RiskRule(BaseModel):
    id: str
    level: RiskLevel            # ACCOUNT / PORTFOLIO / STRATEGY
    metric: str                 # max_drawdown / daily_loss / position_limit
    threshold: float
    action: RiskAction          # ALERT / BLOCK / KILL_SWITCH
    auto_execute: bool          # 是否自动执行

# 订单 (Order)
class Order(BaseModel):
    id: str
    strategy_id: str
    symbol: str
    side: Side                  # BUY / SELL
    quantity: int
    order_type: OrderType       # MARKET / LIMIT / STOP
    limit_price: Optional[float]
    status: OrderStatus
    approvals: List[Approval]
    executions: List[Execution]
    trace_id: str               # 血缘追踪 ID
```

## 6. 安全架构

### 6.1 数据安全

- 数据库连接字符串、API Key 存入 Vault（如 HashiCorp Vault）
- 敏感字段（身份证号、手机号）加密存储
- 数据访问按角色授权（RBAC）

### 6.2 交易安全

- AI Agent **无权**读取、导出、解密 API Key
- 交易系统**不提供**提现/资金划转能力
- 风控规则放宽必须**双人审批**
- 实盘账户与主账户**物理隔离**

### 6.3 系统安全

- API 请求签名验证
- 回测环境禁止访问生产数据库
- 所有操作写入不可篡改审计日志
