## 1. 产品概述

### 1.1 定位

LLMine Quant 前端是面向专业量化交易团队的 **AI-Native 作战室仪表盘**。V1.0.0 完成了全部 11 个功能模块的可视化界面，覆盖从策略研发、回测验证、组合管理、交易执行、风控熔断到审计追踪的完整闭环。

### 1.2 V1.0.0 边界

**已交付：**
- 11 个核心功能屏幕的全部 UI 实现
- 玻璃态暗黑主题设计系统
- ECharts + SVG + CSS 多层可视化体系
- A 股 / Crypto 双市场 Mock 数据切换
- 响应式布局（桌面端 + 移动端适配）
- 全局导航、搜索、Modal、侧边栏折叠

**未包含（后续版本）：**
- 真实后端 API 对接（当前为 Mock 数据层）
- WebSocket 实时推送
- 用户认证与权限系统
- 策略代码编辑器（Monaco/CodeMirror）

### 1.3 设计原则

V1.0.0 前端遵循以下六条核心原则：

1. **零文案宣传** — 界面不出现系统介绍、营销文案，每屏都是作战数据
2. **数据即语言** — 用数字、图表、颜色、动画传达状态，而非文字描述
3. **状态分级** — 全局统一五色状态体系：`green` | `yellow` | `red` | `blue` | `purple`
4. **一屏可见** — 核心信息无需滚动即可获取，滚动仅用于详情展开
5. **随处可点** — 每个卡片、每行数据、每个指标都可点击导航或唤起操作
6. **科技质感** — 玻璃态 (`backdrop-filter: blur(24px)`)、微光、流畅过渡、脉冲呼吸灯

### 2.2 全局组件

| 组件 | 位置 | 功能 |
|------|------|------|
| Sidebar | 左侧固定 | 主导航 + 系统健康卡片，支持折叠展开 |
| Topbar | 顶部固定 | AI 自然语言搜索、Autopilot 状态、Kill Switch、全局概览 |
| Mobile Tabs | 底部固定 | 移动端屏幕切换，展示 6 个核心 Tab |
| Modal Backdrop | 全屏遮罩 | 全局弹窗容器，支持点击外部关闭 |
| Market Bar (Dashboard) | Dashboard 顶部 | 实时市场指数跑马灯 |

### 2.3 导航与路由

- **无前端路由**：屏幕状态由 `App.tsx` 的 `useState<Screen>` 管理，通过条件渲染切换
- **11 个有效屏幕**：`dashboard` | `strategy` | `backtest` | `explain` | `portfolio` | `execution` | `risk` | `data` | `security` | `collaboration` | `audit`
- **6 个 Modal 类型**：`global` | `kill` | `create` | `autopilot` | `approve` | `pause`
- **导航方式**：
  - 侧边栏按钮直接切换
  - 屏幕内组件通过 `onNavigate` / `onModal` 回调跳转
  - Dashboard 快捷操作区一键直达

### 2.4 响应式断点

| 断点 | 行为 |
|------|------|
| >= 1440px | 完整桌面布局，侧边栏展开 |
| 860px - 1439px | 桌面布局，部分网格变为 2 列 |
| <= 859px | 移动端布局，侧边栏隐藏，底部 Tab 栏出现 |

### 6.1 ECharts 使用规范

由于所有屏幕通过 `display: none` 切换，ECharts 在隐藏容器中初始化会得到 0 尺寸。统一使用以下模式：

```typescript
const pendingOptionRef = useRef<any>(null)

useEffect(() => {
  const initOrResize = () => {
    if (!chartRef.current) {
      const rect = el.getBoundingClientRect()
      if (rect.width > 0 && rect.height > 0) {
        chartRef.current = echarts.init(el)
        if (pendingOptionRef.current) {
          chartRef.current.setOption(pendingOptionRef.current, true)
        }
      }
    } else {
      chartRef.current.resize()
    }
  }
  initOrResize()
  const ro = new ResizeObserver(initOrResize)
  ro.observe(el)
  return () => { ro.disconnect(); chartRef.current?.dispose() }
}, [])
```
