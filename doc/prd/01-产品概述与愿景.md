# LLMine Quant — 产品概述与愿景

## 1. 产品定位

LLMine Quant 是面向中国 A 股市场的 **AI-Native 量化投研与交易系统**。一期以「Research + Backtest + Paper Trading」为核心闭环，二期逐步接入实盘交易执行。

与现有量化平台（聚宽、BigQuant、QMT）的核心差异：

| 维度 | 传统平台 | LLMine Quant |
|------|---------|-------------|
| 策略研发 | 代码驱动，门槛高 | 自然语言 + Agent 协作，降低 80% 门槛 |
| 回测质量 | 未来函数/过拟合频发 | 内置 Bias 检测 + Walk-forward 验证 |
| 信号解释 | 黑盒 | 可解释归因 + 血缘追踪 |
| 风控 | 规则静态配置 | AI Risk Agent 动态评估 + 熔断 |
| 协作 | 单人/小团队 | 多人分权 + AI Agent 协作评审 |

## 2. 愿景与目标

### 2.1 愿景

> 让专业级量化投研能力民主化——任何一个有投资想法的人，都能通过自然语言与 AI Agent 协作，在严格的风控与可解释性约束下，快速验证策略、管理组合、执行交易。

### 2.2 一期目标（3 个月）

- **覆盖市场**：沪深 A 股全市场（含主板、科创板、创业板、北交所）
- **核心闭环**：Data → Research → Strategy → Backtest → Paper Trading
- **策略类型**：
  - 规则型（多因子、技术指标、事件驱动）
  - 机器学习型（XGBoost/LightGBM 分类/回归）
  - 组合优化型（均值方差、风险平价、Black-Litterman）
- **数据范围**：日线/分钟线/财务数据/基本面数据/宏观数据

### 2.3 二期目标（6 个月）

- 接入实盘交易（QMT / PTrade / 券商 API）
- 实时行情与盘中信号监控
- 更多策略类型（深度学习、强化学习、高频）
- 机构级功能（多账户管理、算法交易、T0 策略）

## 3. 核心用户画像

| 用户类型 | 需求 | 使用场景 |
|---------|------|---------|
| 个人投资者 | 快速验证选股想法 | 自然语言描述策略 → AI 生成 → 回测 → 模拟盘 |
| 量化研究员 | 高效策略迭代 | Agent 协助参数优化、过拟合检测、样本外验证 |
| 私募交易员 | 风控严格的实盘执行 | 策略评审 → 风控检查 → 人工确认 → 自动下单 |
| 风控合规 | 全程可追溯 | 审计日志、血缘追踪、合规规则自动检查 |

## 4. 产品原则

1. **安全第一**：实盘交易必须 Human-in-the-loop，AI 只生成提案
2. **可解释**：每个信号必须可追溯、可解释、可审计
3. **数据严谨**：内置 A 股特有的数据清洗规则（复权、停牌、ST、退市）
4. **风控闭环**：账户级 + 组合级 + 策略级三层风控
5. **开放架构**：数据层、策略层、执行层可插拔

## 5. 竞品分析

| 产品 | 优势 | 劣势 | LLMine 差异化 |
|------|------|------|--------------|
| 聚宽 (JoinQuant) | 社区活跃、数据全、实盘支持 | 代码门槛高、AI 能力弱 | Agent 协作 + 自然语言 |
| BigQuant | AI 策略生成、可视化 | 黑盒严重、可解释性差 | 可解释归因 + 血缘追踪 |
| QMT | 极速交易、机构级 | 昂贵、封闭、学习曲线陡 | 开放架构 + 低门槛 |
| PTrade | 恒生出品、券商支持好 | 策略灵活性差 | 灵活策略层 + AI 增强 |
| RiceQuant | 回测快、社区好 | 实盘受限、A 股外市场弱 | A 股深度适配 + 风控 |

## 6. 关键指标（一期）

| 指标 | 目标 |
|------|------|
| 策略从想法到回测 | < 5 分钟 |
| 回测过拟合检测通过率 | > 90% |
| 数据清洗准确率 | > 99.9% |
| 模拟盘信号延迟 | < 1 分钟（EOD 策略） |
| 系统可用性 | > 99.5% |

## 7. 术语表

| 术语 | 定义 |
|------|------|
| Agent | 具备特定能力的 AI 智能体（研究/策略/回测/风控/执行） |
| Walk-forward | 滚动窗口回测，避免未来函数 |
| 过拟合 | 策略在样本内表现好，样本外失效 |
| HITL | Human-in-the-loop，关键环节人工确认 |
| Kill Switch | 全局熔断开关，一键停止所有交易 |
| 数据血缘 | 从原始数据到最终信号的完整追溯链 |
| EOD | End of Day，日终数据/策略 |
