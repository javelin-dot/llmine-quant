## 二、v2.0 优化目标

### 2.1 核心设计原则（沿用全系统六原则）

1. **零营销文案** — 数字、颜色、图表传递一切信息  
2. **数据即语言** — 每个像素都应承载量化意义  
3. **状态分级** — green / yellow / red / blue / purple 颜色体系  
4. **一屏可见** — 关键信息不需要滚动  
5. **全区可点** — 每个卡片/行都可导航或展开  
6. **科技美学** — glass-morphism + 径向渐变叠加 + 脉冲点

### 2.2 v2.0 升级范围

**P0（本次必做）：**
- 新增 Calmar 比率、Sortino 比率、年化波动率、盈亏比 4 项后端指标
- 新增月度收益计算（按月聚合净值变化）
- 新增动量策略（cross-sectional momentum）、均值回归策略
- 前端回测工作台重设计：与系统设计语言对齐
- 新增月度收益热图组件（月历视图）
- 扩展指标条（从 6 项扩展至 10 项，2 行）

**P1（后续迭代）：**

## 三、功能设计详细说明

### 3.1 后端指标扩展

#### 新增绩效指标

| 指标 | 计算公式 | 意义 |
|------|----------|------|
| Calmar 比率 | 年化收益 / \|最大回撤\| | 衡量回撤调整后收益率，>1.0 优秀 |
| Sortino 比率 | 超额收益均值 / 下行标准差 × √252 | 只惩罚下行风险，比 Sharpe 更精确 |
| 年化波动率 | 日收益标准差 × √252 | 投资组合的年化风险水平 |
| 盈亏比（Profit Factor） | Σ正收益 / Σ负收益绝对值 | >1.5 表示盈利稳健 |

#### 月度收益结构

```
monthly_returns: dict[str, float]
  key: "YYYY-MM"  (e.g., "2024-03")
  value: 该月收益率（小数）
```

按月取期初/期末净值计算，OOS 阶段与 IS 阶段独立标记。

#### 策略库扩展

**Momentum（动量策略）**
- 参数：lookback=20, skip=1, max_positions=5, target_gross=0.95
- 信号：计算各标的过去 lookback 天（跳过最近 skip 天）的收益率排名
- 行为：买入排名前 max_positions 的标的，等权分配

**MeanReversion（均值回归策略）**
- 参数：lookback=20, z_threshold=1.5, max_positions=10, target_gross=0.90
- 信号：计算各标的最近 lookback 天日收益的 Z-score
- 行为：买入 z-score < -z_threshold 的超跌标的（反弹预期）

### 3.2 前端工作台重设计

#### 布局架构

```
┌─────────────────────────────────────────────────────────────┐
│  HEADER: 策略标题 + 状态点 + [运行回测] [WF] [敏感性]       │
├──────────────┬────────────────────────────┬─────────────────┤
│              │  指标条（10项，2行）         │                 │
│  配置面板    │  ─────────────────────────  │  运行历史        │
│  (glass卡)   │  结果标签页                 │  (带 sparkline)  │
│  · 策略选择  │  [总览][月度][WF][敏感性]   │                 │
│  · 股票池    │  [成交][过拟合]             │                 │
│  · 日期范围  │                            │                 │
│  · IS切分    │  图表/表格区域              │                 │
│  · 参数展开  │                            │                 │
│  · 成本展开  │                            │                 │
└──────────────┴────────────────────────────┴─────────────────┘
```

#### 月度收益热图（新 Tab）

```
           Jan  Feb  Mar  Apr  May  Jun  Jul  Aug  Sep  Oct  Nov  Dec   YTD
  2023     +2.1 -0.8 +3.4 +1.2 +4.1 -1.5 +2.8 +0.9 +3.1 -2.3 +1.8 +4.2  +21.3
  2024     +1.4 +2.9 -1.1 +3.6 +0.8 +2.2 +1.7 -0.6 +2.4 +3.1 -0.9 +1.3  +19.1
```

- 每格颜色：red（负）→ white（零）→ green（正），线性插值
- 每格文字：百分比数值（+/- 前缀）
- 第 13 列显示年度累计收益

#### 指标条扩展（10 项）

第一行（核心收益）：累计收益 | 年化收益 | 最大回撤 | Sharpe 比率  
第二行（深度风险）：Sortino 比率 | Calmar 比率 | 年化波动率 | 盈亏比 | 胜率 | 换手率

#### 历史面板升级

每条历史记录增加：
- 策略类型标签（dual_ma / momentum / mean_rev）
- 过拟合等级色块
- 小型 sparkline（10个 SVG 点，显示净值曲线走势）

```json
{
  "cumulativeReturn": 0.371,
  "annualReturn": 0.185,
  "maxDrawdown": -0.123,
  "sharpeRatio": 1.34,
  "winRate": 0.582,
  "turnover": 2.41,
  "calmarRatio": 1.50,    // NEW
  "sortinoRatio": 1.82,   // NEW
  "volatility": 0.124,    // NEW（年化）
  "profitFactor": 1.73    // NEW
}
```

### 4.2 `BacktestTaskResultOut` 新增字段

```json
{
  "taskId": "...",
  "monthlyReturns": {       // NEW
    "2024-01": 0.021,
    "2024-02": -0.008,
    "2024-03": 0.034
  },
  "summary": { ... }
}
```

### 4.3 策略 API 参数扩展

策略名称现支持：`dual_ma` | `momentum` | `mean_reversion`

各策略 `strategyParams` 参数规格：

```json
// momentum
{
  "lookback": 20,
  "skip": 1,
  "max_positions": 5,
  "target_gross": 0.95
}

// mean_reversion
{
  "lookback": 20,
  "z_threshold": 1.5,
  "max_positions": 10,
  "target_gross": 0.90
}
```
