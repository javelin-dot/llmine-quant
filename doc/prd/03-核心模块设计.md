### 3.3 过拟合检测

```python
class OverfitDetector:
    """多维度过拟合检测"""

    def check(self, is_results: BacktestResult,
              oos_results: BacktestResult) -> OverfitReport:
        report = OverfitReport()

        # 1. 样本外/样本内收益比
        report.oos_ratio = oos_results.annual_return / max(is_results.annual_return, 1e-6)
        report.oos_ratio_pass = report.oos_ratio > 0.6

        # 2. 参数稳定性
        report.param_stability = self._check_param_stability()
        report.param_stability_pass = report.param_stability > 0.5

        # 3. 滑点敏感性
        report.slippage_robustness = self._check_slippage_robustness()
        report.slippage_robustness_pass = report.slippage_robustness > 0.7

        # 4. 夏普比率衰减
        report.sharpe_decay = oos_results.sharpe_ratio / max(is_results.sharpe_ratio, 1e-6)
        report.sharpe_decay_pass = report.sharpe_decay > 0.5

        # 综合评分
        report.overall_score = self._calc_overall_score(report)
        report.overfit_level = self._classify(report.overall_score)

        return report
```

### 3.4 回测报告生成

回测报告包含以下部分：

1. **绩效概览**
   - 累计收益、年化收益、最大回撤、夏普比率
   - 与基准对比（超额收益、信息比率）

2. **月度/年度收益分布**
   - 月度收益热力图
   - 年度收益对比

3. **回撤分析**
   - 回撤区间、恢复时间
   - 连续亏损天数

4. **交易分析**
   - 胜率、盈亏比、平均盈利/亏损
   - 持仓周期分布
   - 行业/板块分布

5. **风险指标**
   - VaR、CVaR、Beta、Alpha
   - 滚动夏普、滚动回撤

6. **过拟合评估**
   - 样本内外一致性
   - 参数稳定性
   - 综合风险等级

7. **情景分析**
   - 牛市/熊市/震荡市表现
   - 2015 股灾、2018 熊市、2020 疫情、2024 波动

### 4.2 熔断规则

| 熔断类型 | 触发条件 | 自动动作 | 恢复方式 |
|---------|---------|---------|---------|
| 可恢复熔断 | 行情延迟 > 5min / 策略心跳异常 | 暂停新开仓，允许平仓 | 自动恢复 |
| 不可恢复熔断 | 资金异常 / 重复下单 / 风控服务宕机 | 全部暂停，冻结账户 | 人工审批恢复 |
| 组合熔断 | 组合回撤 > 15% | 减仓至 50% 仓位 | 人工审批恢复 |
| 全市场熔断 | 大盘单日跌幅 > 7%（参考 A 股） | 清仓或暂停 | 次日自动恢复 |
