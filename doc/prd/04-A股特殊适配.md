## 1. 交易制度适配

### 1.1 T+1 制度

A 股实行 T+1 交收制度，当日买入的股票当日不得卖出。

**回测引擎处理：**

```python
class T1Constraint:
    """T+1 约束检查"""

    def __init__(self):
        self.buy_dates: Dict[str, date] = {}  # symbol -> first_buy_date

    def can_sell(self, symbol: str, today: date) -> bool:
        """检查某股票今日是否可以卖出"""
        if symbol not in self.buy_dates:
            return True  # 之前持有的可以卖
        first_buy = self.buy_dates[symbol]
        return (today - first_buy).days >= 1

    def on_buy(self, symbol: str, date: date):
        """记录买入日期"""
        if symbol not in self.buy_dates:
            self.buy_dates[symbol] = date

    def on_sell(self, symbol: str, quantity: int, holdings: Dict[str, int]):
        """
        卖出时优先卖出可卖部分：
        - 先卖 T 日前持有的（老持仓）
        - 再卖昨日买入的（新持仓，如果允许）
        """
        pass
```

**策略影响：**
- 日内回转策略受限（需已有底仓）
- 高频策略需特别关注持仓状态
- 止损信号可能延迟执行（当日买入无法当日止损）

**回测引擎处理：**

```python
class PriceLimitChecker:
    def __init__(self):
        self.limit_rules = {
            'main': 0.10,
            'st': 0.05,
            'kcb': 0.20,   # 科创板
            'cyb': 0.20,   # 创业板
            'bse': 0.30,   # 北交所
        }

    def get_limit_price(self, symbol: str, prev_close: float,
                        side: Side) -> float:
        """计算涨跌停价格"""
        board = self._get_board(symbol)
        limit_pct = self.limit_rules[board]

        if side == BUY:
            return round(prev_close * (1 + limit_pct), 2)
        else:
            return round(prev_close * (1 - limit_pct), 2)

    def is_limit_up(self, symbol: str, open_price: float,
                    high_price: float, prev_close: float) -> bool:
        """是否一字涨停（开盘价=最高价=涨停价）"""
        limit_price = self.get_limit_price(symbol, prev_close, BUY)
        return abs(open_price - limit_price) < 0.01 and abs(high_price - limit_price) < 0.01

    def can_execute(self, symbol: str, side: Side,
                    bar: Bar) -> Tuple[bool, str]:
        """
        检查订单是否可成交：
        - 涨停：买单无法成交（除非排板）
        - 跌停：卖单无法成交（除非排板）
        - 回测中通常简化处理：涨停不买入，跌停不卖出
        """
        if side == BUY and self.is_limit_up(symbol, bar.open, bar.high, bar.prev_close):
            return False, "涨停无法买入"
        if side == SELL and self.is_limit_down(symbol, bar.open, bar.low, bar.prev_close):
            return False, "跌停无法卖出"
        return True, ""
```

### 3.2 滑点模型

```python
class SlippageModel:
    """A 股滑点模型"""

    def fixed_slippage(self, price: float, side: Side,
                       slippage_pct: float = 0.001) -> float:
        """固定比例滑点"""
        if side == BUY:
            return price * (1 + slippage_pct)
        return price * (1 - slippage_pct)

    def volume_weighted_slippage(self, price: float, volume: int,
                                  order_amount: int,
                                  side: Side) -> float:
        """
        基于成交量的滑点：
        - 大单冲击成本更高
        - 参考盘口深度
        """
        impact = min(order_amount / volume * 0.1, 0.01)
        if side == BUY:
            return price * (1 + impact)
        return price * (1 - impact)
```

## 4. 策略 A 股化示例

### 4.1 双均线策略（A 股适配版）

```python
class DoubleMAStrategyASHARE(RuleBasedStrategy):
    """
    双均线策略 - A 股适配版

    适配点：
    1. T+1：当日信号次日执行
    2. 涨跌停：涨停不买，跌停不卖
    3. ST 过滤：排除 ST 股票
    4. 停牌过滤：排除停牌股票
    5. 新股过滤：排除上市 60 日内新股
    """

    def initialize(self, context):
        context.universe = get_all_stocks(
            exclude_st=True,
            exclude_new=True,
            new_listing_days=60
        )
        context.short_window = 20
        context.long_window = 60
        context.max_holding = 50
        context.max_position_pct = 0.02  # 单票 2%

    def generate_signals(self, context, data):
        signals = {}

        for symbol in context.universe:
            # 跳过停牌
            if data.is_suspended(symbol):
                continue

            # 跳过涨停（不买入）
            if data.is_limit_up(symbol):
                continue

            short_ma = data.ma(symbol, context.short_window)
            long_ma = data.ma(symbol, context.long_window)

            if short_ma > long_ma * 1.02:  # 金叉 + 2% 缓冲
                signals[symbol] = Signal(
                    side=BUY,
                    weight=1.0,
                    reason=f"MA{context.short_window} 上穿 MA{context.long_window}"
                )
            elif short_ma < long_ma * 0.98:  # 死叉
                # 检查是否可卖（T+1、跌停）
                if self.can_sell(context, symbol):
                    signals[symbol] = Signal(
                        side=SELL,
                        weight=1.0,
                        reason=f"MA{context.short_window} 下穿 MA{context.long_window}"
                    )

        # 限制持仓数量
        return self.select_top(signals, context.max_holding)
```

### 4.2 多因子选股策略（A 股版）

```python
class MultiFactorStrategyASHARE(RuleBasedStrategy):
    """
    多因子选股策略 - A 股版

    因子：
    - 价值：PE（越低越好）
    - 质量：ROE（越高越好）
    - 动量：60日涨幅（越高越好）
    - 情绪：20日换手率（适中，排除极端）

    A 股适配：
    - 财务数据发布滞后处理
    - 年报/季报切换处理
    - 行业中性化
    """

    def initialize(self, context):
        context.universe = get_all_stocks(exclude_st=True)
        context.rebalance_freq = '1M'  # 月度调仓
        context.max_holding = 30
        context.industry_neutral = True  # 行业中性

    def generate_signals(self, context, data):
        # 获取最新财务数据（处理发布延迟）
        fundamentals = data.get_fundamentals(
            fields=['pe', 'roe', 'revenue_growth'],
            as_of_date=context.prev_trading_date
        )

        # 获取技术指标
        technicals = data.get_technical(
            fields=['mom_60', 'turnover_20'],
            window=20
        )

        # 合并因子
        factors = pd.merge(fundamentals, technicals, on='symbol')

        # 因子预处理
        factors['pe_score'] = self._rank_ascending(factors['pe'])
        factors['roe_score'] = self._rank_descending(factors['roe'])
        factors['mom_score'] = self._rank_descending(factors['mom_60'])
        factors['turnover_score'] = self._rank_middle(factors['turnover_20'])

        # 合成得分
        factors['total_score'] = (
            0.3 * factors['pe_score'] +
            0.3 * factors['roe_score'] +
            0.25 * factors['mom_score'] +
            0.15 * factors['turnover_score']
        )

        # 行业中性化（每个行业选前 N 名）
        if context.industry_neutral:
            selected = self._industry_neutral_select(
                factors, max_per_industry=3
            )
        else:
            selected = factors.nlargest(context.max_holding, 'total_score')

        return {row.symbol: Signal(BUY, 1/len(selected))
                for _, row in selected.iterrows()}
```

## 7. 监管合规要点

### 7.1 数据合规

- 实盘数据源必须来自 **持牌数据供应商** 或 **券商授权接口**
- Research Only 数据（如 AKShare）仅限研究与模拟盘，**禁止**用于实盘信号
- 数据使用记录留存不少于 3 年

### 7.2 交易合规

- 禁止利用未公开信息交易（内幕交易）
- 禁止操纵市场价格（对倒、虚假申报）
- 程序化交易需向交易所报备（如符合阈值）
- 遵守交易所异常交易监控规则

### 7.3 系统合规

- 交易日志完整留存，不可篡改
- 风控规则独立于策略执行
- 关键操作双人复核
- 系统变更留有审计记录
