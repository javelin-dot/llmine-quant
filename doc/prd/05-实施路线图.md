# LLMine Quant — 实施路线图

## 项目概览

| 阶段 | 周期 | 目标 | 交付物 |
|------|------|------|--------|
| Phase 0 | 第 1-2 周 | 基础设施 + 数据层 | 可运行的数据管道 |
| Phase 1 | 第 3-6 周 | 回测引擎 + 策略层 | 完整回测闭环 |
| Phase 2 | 第 7-10 周 | AI Agent + 前端 | 可视化策略研发平台 |
| Phase 3 | 第 11-12 周 | 风控 + 模拟盘 | 模拟盘运行 + 风控闭环 |
| Phase 4 | 第 13-16 周 | 优化 + 实盘准备 | 性能优化 + 实盘接口 |
| Phase 5 | 第 17-20 周 | 机构级功能 | 多账户 + 算法交易 |

## 技术债务与风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| AKShare 数据不稳定 | 数据缺失/延迟 | 多源备份（AKShare + Tushare） |
| LLM 生成代码质量不稳定 | 策略逻辑错误 | 静态检查 + 沙箱运行 + 人工确认 |
| A 股规则变化 | 回测失真 | 规则配置化，快速更新 |
| 实盘接口差异 | 券商适配成本高 | 抽象交易接口，统一封装 |
| 性能瓶颈 | 回测太慢 | 向量化、并行化、增量计算 |
