# 2026-05-16 — Agent Studio UX Slice 1：三工作区骨架

## 目标

将原本把 Agent 定义、工作流编排、发布和运行调试混在一起的单页，拆成三个清晰工作区：

- `Agents`
- `Workflows`
- `Runs`

本轮只做**结构性重排**，不改后端，不重写已有业务能力，目标是先把 Agent Studio 的心智模型立住。

## 设计取舍

- **不继续强化单页**：当前最大问题不是样式，而是不同任务混在一个平面上。
- **先拆工作区，再做细节优化**：如果先改编辑器、画布和调试细节，后续仍会被单页结构拖累。
- **保留全部现有能力**：
  - Agent 定义编辑仍在 `Agents`
  - 画布、校验、发布仍在 `Workflows`
  - 调试运行迁移到 `Runs`

## 代码改动

### 前端

- `frontend/src/screens/Agent/index.tsx`
  - 新增 `workspace` 状态
  - 新增三工作区导航
  - 将原有能力按 `Agents / Workflows / Runs` 重新分区
  - 新增工作区说明文案，帮助用户理解对象边界
- `frontend/src/styles/prototype.css`
  - 新增工作区导航样式
  - 新增工作区 intro 样式
  - 新增 Runs 顶部工作流选择区域样式

## 结果

Agent Studio 已从“单页堆叠”进入“工作区分层”阶段。  
后续可以在不打乱整体结构的前提下，分别优化：
