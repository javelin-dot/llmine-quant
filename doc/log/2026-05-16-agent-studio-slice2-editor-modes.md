# 2026-05-16 — Agent Studio UX Slice 2：编辑器分层

## 目标

在不删减任何 Agent 配置字段的前提下，降低首次使用门槛：

- 默认进入 **引导模式**
- 需要完整底层配置时，再切换到 **专家模式**

## 设计取舍

- **字段一个不删**：仍然保留模型配置、Schema、映射、工具权限、约束、运行策略等完整能力。
- **复杂度后置**：常用配置优先展示，原始 / 标准化 Schema 与治理策略先展示摘要。
- **专家能力可达**：用户可以一键进入专家模式，继续编辑完整 JSON。

## 代码改动

### 前端

- `frontend/src/screens/Agent/index.tsx`
  - 新增 `editorMode`
  - 增加引导模式 / 专家模式切换
  - 在引导模式下：
    - 模型页隐藏底层 JSON
    - 契约页显示字段摘要卡
    - 映射与约束页显示治理摘要卡
  - 在专家模式下：
    - 保持完整 JSON 编辑能力
- `frontend/src/styles/prototype.css`
  - 新增模式切换区样式
  - 新增摘要面板与摘要卡样式

## 验证

- 结果：通过

### 浏览器验证

验证了：

结果：通过。
