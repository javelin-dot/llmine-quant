# 2026-05-16 — Agent Studio UX Slice 5：编辑器组件化增强

## 目标

继续降低 Agent 编辑门槛，把当前最常见、也最容易让用户卡住的两类配置从“看摘要 / 改 JSON”推进为“可直接编辑”：

- Prompt
- Schema

## 本轮交付

### 前端

- `frontend/src/screens/Agent/index.tsx`
  - 新增 `PromptEditor`
    - 自动识别 `{{variable}}`
    - 展示变量标签
    - 提供模板即时预览
  - 新增 `SchemaEditor`
    - 引导模式下支持字段表编辑
    - 支持新增 / 删除 / 重命名字段
    - 支持字段类型、说明、必填状态维护
  - 新增 `ContractEditor`
    - 在引导模式中承载“原始输入输出 / 标准化结构”的字段化编辑
    - 仍保留切换到专家 JSON 的入口
- `frontend/src/styles/prototype.css`
  - 新增 Prompt 编辑器样式
  - 新增契约编辑器与字段表样式
  - 补充窄屏响应式布局

## 设计取舍

- **不删除专家 JSON**：完整能力继续保留，避免为了易用性牺牲表达力。
- **把“能看懂”升级为“能直接改”**：Slice 2 只解决了复杂度前置问题，本轮开始解决真正的编辑摩擦。
- **优先处理高频动作**：Prompt 与 Schema 是 Agent 配置里最常被修改、也最影响后续工作流连线质量的两块，先做它们的产品化收益最高。

## 结果

Agent 编辑器已经从“默认看摘要，复杂时改 JSON”进入“常见配置可视化直编”的阶段。  
这一步会直接降低第一次上手和日常维护的认知成本，也为后续把页面进一步拆成独立组件做好了边界准备。
